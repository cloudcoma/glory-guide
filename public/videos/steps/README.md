# Видео для отдельных шагов

В эту папку можно добавить 11 коротких MP4-роликов — по одному для каждого
действия инструкции. Рекомендуемые имена:

- `step-1.mp4`
- `step-2.mp4`
- `step-3.mp4`
- `step-4.mp4`
- `step-5.mp4`
- `step-6.mp4`
- `step-7.mp4`
- `step-8.mp4`
- `step-10.mp4`
- `step-11.mp4`
- `step-12.mp4`

Просто положите ролик в эту папку и обновите страницу. Сайт сам найдёт файл по
номеру шага и покажет его под кнопкой «Посмотреть видео» — менять код не нужно.
Если файла пока нет, останется аккуратная заглушка.

В шаге 9 кнопка «Посмотреть видео» отключена, поэтому `step-9.mp4` не нужен.

Имена должны точно соответствовать списку выше и состоять из маленьких букв.
Для надёжного воспроизведения на iPhone используйте MP4 с видео H.264 и звуком
AAC. Если вместо файла нужна отдельная ссылка Telegram, YouTube или RuTube,
передайте её Codex.
