# Иллюстрации инструкции Glory IOS

На странице используются фотографии и иллюстрации `step-1.webp` … `step-12.webp`. Изображения сохранены в оптимизированном формате WebP; общий размер двенадцати файлов — 646 026 байт. Страница показывает изображение текущего шага с исходными пропорциями, без обрезки.

- `step-1.webp` — «Проверить UDID» и отправка своего UDID;
- `step-2.webp` — «Получить сертификат»;
- `step-3.webp` — выбор ESign и «Установить»;
- `step-4.webp` — включение режима разработчика;
- `step-5.webp` — сохранение `.p12` и `.mobileprovision` в «На моём iPhone»;
- `step-6.webp` — меню ESign и «Импорт»;
- `step-7.webp` — импорт `.p12`, затем `.mobileprovision`;
- `step-8.webp` — импорт сертификата `.p12` с паролем `1`;
- `step-9.webp` — сохранение `.ipa` в память устройства;
- `step-10.webp` — импорт `.ipa` в ESign;
- `step-11.webp` — «Приложения» → нужное приложение → «Подписать»;
- `step-12.webp` — установка и повторное подтверждение.

Для замены изображения сохраните новую фотографию или скриншот в формате WebP под тем же именем. Сохраняйте видимыми нужную кнопку и действие; используйте чёткий исходник. Если нужна помощь с подготовкой, передайте изображение Codex. При сохранении того же имени менять подключение не нужно. После отправки изменений на GitHub дождитесь окончания автоматической публикации.

Векторные файлы `step-1.svg` … `step-12.svg` оставлены как неиспользуемые варианты. Страница инструкции их не загружает.

Пути изображений, альтернативный текст и подписи находятся в `src/data/guide.ts`.
