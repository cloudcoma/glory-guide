# Glory IOS — инструкция для Telegram Mini App

Мобильная инструкция по установке приложений на iPhone: двенадцать шагов с иллюстрациями и видео, отдельная страница частых ошибок и ссылки поддержки. В Telegram она открывается по кнопке **«Инструкция»** в сообщении бота о готовом сертификате.

Проект подготовлен для **GitHub Pages**. GitHub хранит файлы, собирает сайт и выдаёт публичный HTTPS-адрес. Netlify и отдельный сервер для этой инструкции не нужны. Подготовка файлов на компьютере сама по себе ещё не публикует сайт в интернете.

Пошаговая памятка по загрузке на GitHub, публикации и подключению кнопки бота находится в [PUBLISH-MINIAPP.md](PUBLISH-MINIAPP.md).

## Папки проектов

| Папка | Назначение |
| --- | --- |
| `C:\Users\pc\Desktop\Glory-Guide` | Эта инструкция для Telegram Mini App |
| `C:\Users\pc\Desktop\Glory-Bot` | Telegram-бот, который выдаёт сертификаты и кнопку инструкции |
| `C:\Users\pc\Desktop\Glory-Store` | Задание и будущий сайт магазина |

В репозиторий инструкции загружается содержимое только Glory-Guide. Функции магазина, оплата, личный кабинет и админ-панель относятся к отдельному проекту Glory-Store.

## Как открыть сайт на этом компьютере

1. В папке проекта дважды нажмите **Start-Glory.cmd**.
2. Дождитесь строки `Local: http://localhost:3000` или похожего адреса с другим номером порта.
3. Откройте этот адрес в браузере. Появится главная страница Glory IOS.

Оставьте окно запуска открытым, пока смотрите сайт. Чтобы остановить сайт, нажмите в этом окне **Ctrl + C**. Если порт 3000 занят, запуск автоматически выберет свободный порт до 3010.

Этот способ использует уже установленные зависимости проекта и доступный Node.js, включая встроенный в Codex Node.js на этом компьютере. Если появится сообщение об отсутствии Node.js или зависимостей, воспользуйтесь следующим способом.

## Запуск через npm

Для такой же среды, как при публикации, используйте **Node.js 24** с npm. Установщик доступен на [сайте Node.js](https://nodejs.org/). После установки закройте и заново откройте терминал.

1. Откройте папку проекта в Проводнике.
2. Нажмите на адресную строку, введите `powershell` и нажмите Enter. Откроется терминал в этой папке.
3. Установите зависимости проекта:

   ```powershell
   npm ci
   ```

4. Запустите просмотр с автоматическим обновлением после изменений:

   ```powershell
   npm run dev
   ```

5. Откройте адрес из строки `Local` в браузере. Обычно это `http://localhost:3000`.

Для просмотра на iPhone телефон и компьютер должны быть подключены к одной Wi-Fi сети. Вместо `localhost` понадобится локальный IP-адрес компьютера, например `http://192.168.1.10:3000`; Windows также должна разрешать доступ к серверу. Адрес `0.0.0.0` не подходит для открытия на телефоне. Это локальный просмотр; для кнопки Mini App нужен опубликованный HTTPS-адрес из GitHub Pages.

## Что уже есть

| Адрес внутри сайта | Содержимое |
| --- | --- |
| `/` | Главная страница, начало установки, видео, ошибки и поддержка |
| `/guide/` | Двенадцать шагов с прогрессом, подсказками и переходами в Telegram |
| `/guide/errors/` | Пять частых ошибок, решения и обращение в поддержку |

При публикации репозитория `glory-guide` адрес инструкции обычно имеет вид `https://ВАШ-ЛОГИН.github.io/glory-guide/guide/`. Точный адрес нужно брать из раздела **Settings → Pages** своего репозитория.

Проект использует Next.js с App Router, React, TypeScript и Tailwind CSS. Сборка создаёт статические страницы в папке `out`. Переходы между шагами работают в браузере, поэтому для инструкции не нужны база данных, сервер Next.js и авторизация пользователя. При открытии внутри Telegram подключается интерфейс Mini App.

## Где хранится контент

| Что нужно заменить | Где находится |
| --- | --- |
| Тексты двенадцати шагов, предупреждения, подсказки и пути иллюстраций | `src/data/guide.ts` |
| Благодарность и просьба оставить отзыв | `src/data/guide-completion.ts` |
| Категории ошибок и ответы FAQ | `src/data/faq.ts` |
| Название, описание сайта, ссылки поддержки, бота, канала и отзывов | `src/config/site.ts` |
| Прозрачный символ логотипа без фона | `public/images/brand/glory-symbol.png` |
| Фотографии и иллюстрации шагов `step-1.webp` … `step-12.webp` | `public/images/guide/` |
| Одиннадцать видео шагов; для шага 9 ролик не нужен | `public/videos/steps/` |
| Настройки источников видео | `src/data/video.ts` |
| Компонент видео | `src/components/guide/GuideVideo.tsx` |
| Подключение к Telegram Mini App | `src/components/telegram/TelegramMiniApp.tsx` |
| Автоматическая публикация GitHub Pages | `.github/workflows/deploy-pages.yml` |

В шагах используются прежние фотографии и иллюстрации в оптимизированном формате WebP. Все двенадцать изображений вместе занимают около 646 КБ; при открытии шага загружается его изображение. Чтобы заменить фотографию или изменить её содержание, передайте материалы Codex: он обновит нужный файл. Сохранённые SVG-схемы не подключены к инструкции.

Для видео используйте имена `step-1.mp4`, `step-2.mp4`, …, `step-12.mp4` в `public/videos/steps/`. В шаге 9 видеокнопка отключена, поэтому `step-9.mp4` не требуется. Существующий ролик можно заменить файлом с тем же именем. Для надёжного воспроизведения на iPhone используйте MP4 с видео H.264 и звуком AAC. Для другой ссылки или формата попросите Codex обновить настройки.

## Проверка и просмотр готовой сборки

```powershell
npm run lint
npm run typecheck
npm run build
npm start
```

Первые две команды проверяют код, третья создаёт готовый сайт в `out`, последняя открывает локальный сервер просмотра этой сборки. Используйте адрес, который появится в терминале. После изменений сначала повторите `npm run build`: `npm start` показывает уже собранные файлы.

В GitHub Actions публичный адрес и путь репозитория задаются автоматически по настройкам Pages. Вручную создавать `.env` для обычной публикации не требуется. `.env.example` содержит безопасный пример для локальных настроек.

## Публикация и дальнейшие изменения

Следуйте [памятке публикации](PUBLISH-MINIAPP.md). Перед подключением кнопки пройдите инструкцию на iPhone, проверьте ссылки бота и поддержки, соответствие действий вашей версии iOS и ESign, а также воспроизведение видео внутри Telegram.

После первого подключения GitHub Pages обновление выглядит так: изменить файлы → **Commit to main** в GitHub Desktop → **Push origin** → дождаться успешной публикации в **Actions**. Адрес Mini App сохраняется, пока не меняются имя репозитория или настройки домена.
